

# Agnibho - Personal Portfolio

A clean, responsive, and modern personal portfolio website built with vanilla HTML, CSS, and JavaScript. Designed to showcase professional background, technical skills, projects, and contact information with smooth scroll-triggered animations.

## ✨ Features
- 🌙 Dark theme with easily customizable CSS variables
- 📱 Fully responsive layout (Flexbox & CSS Grid)
- ✨ Scroll-based section reveal animations
- 📂 Dedicated sections for About, Skills, Projects, and Contact
- ⚡ Lightweight with zero external dependencies or build tools

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Custom Properties, Flexbox, Grid, Transitions)
- **JavaScript** (ES6+, Viewport detection for scroll animations)

## 🚀 Usage & Setup

This is a static website that requires no installation or package management.

1. Clone the repository:
   ```bash
   git clone https://github.com/Agnibho-8/agnibho.git
   ```
2. Navigate to the project directory:
   ```bash
   cd agnibho
   ```
3. Open `index.html` directly in any modern web browser, or run a local static server:
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   # Or using Node.js
   npx serve
   ```

## 🌐 Deployment
Since the project contains only static files, it can be deployed to any hosting provider:
- **GitHub Pages**: Go to repository Settings → Pages → Select `main` branch and save.
- **Netlify / Vercel / Cloudflare Pages**: Connect the repository or drag-and-drop the folder for instant deployment.
